# Sketch 003: Hero Illustration Concept

## Design Question
What kind of functional interface should the right-side hero illustration be? Three directions that extend the code-editor language from the navbar.

## How to View
open .planning/sketches/003-hero-illustration/index.html

## Variants
- **A: Terminal** — Dark terminal window with a deploy command sequence typing out. Shows a real build process. Functional, shows "this person ships."
- **B: Code Editor** — Mini code editor with file tabs, line numbers, syntax-highlighted React/TypeScript code. Extends the navbar's code-editor aesthetic directly.
- **C: Dashboard** — Project stats, language bars, activity graph. Data-driven, shows competence through numbers.

## What to Look For
- Which feels most like "proof of craft" rather than decoration?
- Does the terminal feel too terminal-ish (everyone has one)?
- Does the code editor feel too busy or just right?
- Does the dashboard feel too dashboard-y or data-rich?
- Which one would make you stop scrolling and look?
