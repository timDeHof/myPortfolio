# Sketch 001: Nav Link Personality

## Design Question

How should the navigation links present themselves on desktop — what personality do they carry?

## How to View

```bash
open .planning/sketches/001-nav-link-personality/index.html
```

## Variants

- **A: Code-Editor** — Monospace font, `//` prefix on each link, blinking cursor on hover/active. Sharp corners, techy feel. Speaks the language of code.
- **B: Floating Pills** — Rounded bar centered in viewport, each link is a pill. Active state uses brand color with glow. Bold, self-contained, confident.
- **C: Underline Sweep** — Clean text links with an accent underline that sweeps in from left on hover. Minimal base, fluid motion. Brand icon rotates on hover.
- **★ D: Synthesis** — Code-editor monospace + `//` prefix + blinking cursor inside a centered floating pill bar. Active pill fills blue with glow. Resume gets a pill button.
- **★ E: Scroll Morph** — Full-width code-editor bar at top. On scroll, morphs into a compact floating terminal panel — sharp corners, blue accent left border, dark glass background, `//` prefix shrinks but stays visible. Brand name hides leaving just the icon. **Winner.**

## What to Look For

- **Hover behavior** — Does the cursor blink (A/D) feel alive? Does the pill background (B) feel fluid? Does the sweep underline (C) feel smooth?
- **Active state** — Which active indicator is most readable? The cyan tint (A), the blue glow (B), the solid underline (C), or the filled pill (D)?
- **Brand cohesion** — Does the brand treatment feel consistent with the link style?
- **Techy balance** — Which variant best balances "confident engineer" with "approachable human"?
