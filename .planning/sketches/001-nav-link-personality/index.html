★ Variant E: Scroll Morph

The navbar starts as a full-width code-editor bar. Scroll down and it morphs into a compact floating terminal panel — sharp corners, accent left border, monospace everything.

↓

What changes on scroll

The bar shrinks from full-width to a centered floating panel. Background goes dark glass. A blue accent line appears on the left edge. Brand name hides, leaving just the icon. Links tighten up. Everything stays sharp — no pills, no rounds. It's a code editor toolbar that detached from the wall and started floating.

Key design decisions

Sharp corners everywhere. Monospace font stays. The // prefix shrinks but never disappears. The cursor still blinks on hover. The active state uses a subtle blue tint with an inset border — like a selected line in an editor. The accent left border is the signature detail: it says "this is a code panel."

Scroll more to see the morph in action

The transition uses ease-out-expo — fast start, smooth settle. 500ms for the container, 400ms for inner elements. Everything animates together so it feels like one fluid motion, not a cascade of properties.
