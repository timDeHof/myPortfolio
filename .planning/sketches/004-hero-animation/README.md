# Sketch 004: Hero Animation Feel

## Design Question
Once we've chosen the illustration concept (from Sketch 003), how should it breathe? Three animation approaches for the terminal illustration.

## How to View
open .planning/sketches/004-hero-animation/index.html

## Variants
- **A: Typing** — Characters appear one by one, cursor blinks, lines reveal sequentially. Feels like someone is actively working. The most "live" option.
- **B: Streaming** — Lines fade in from below like a log output. No typing effect, just content arriving. Feels like watching a build process. Smoother, less frantic.
- **C: Ambient** — Static content with a gentle floating animation and a gradient border glow. Feels like the terminal is alive but idle. Subtlest option.

## What to Look For
- Typing: Does it feel alive or distracting? Does it pull attention from the CTAs?
- Streaming: Does it feel smooth or too fast/slow? Is the slide-up pleasant?
- Ambient: Does it feel alive enough or too static? Does the glow add or subtract?
- Which animation makes you want to watch vs. ignore?
